VoDo.txt

An Android to do application based using the todo.txt format plus robust task recurrence and Google Drive integration.

VoDo.txt was born from the end of development of SimpleTask and dissatisfaction with the current alternatives. With the exception of recurrence, VoDo.txt uses the standard todo.txt format with a focus on speed.

Quick Start: Initial Setup

When you first launch VoDo.txt, you'll be given a Welcome Setup screen. Click the button to choose a location on your device. VoDo.txt will automatically create a vodo.txt subfolder and initialize your todo.txt and done.txt (archive) files. If you do not want to use these files, you can specifically select which files you would like to use in the "Files" section of settings.

Google Drive Sync

  • Enable Sync: In Settings, toggle "Enable Google Drive Sync."
  • Vodo.txt folder: A "vodo.txt" folder will be created in the root of your Google Drive. You can always move this folder to a new location.
  • Conflict Resolution: If a task is changed on your phone and Drive simultaneously, VoDo.txt will warn you and create a backup in your Conflicts Folder.
  • Manual Sync: You can force a sync by swiping down.

Note: If you have a pre-existing todo.txt file, you can either put it on your Android and select it as the todo.txt file, or you can directly edit the text file on Google Drive using a Workspace text editor and paste your file into its contents.

Managing Tasks

Adding a Task

Tap the [+] button. The Task Details dialog will open:

  • Auto-Population: If you have active filters, the task field is automatically prepopulated with priority, date, and tags.
  • Smart Formatting: You can type directly in the task field or use the buttons to add tags.
  • Creation Date: If enabled in Settings, the current date is added automatically.
  • Dynamic Priorities, Contexts, and Projects: The only priorities, contexts, and tags available in the pull down menus will be those currently in use. If you would like to create additional priorities, contexts, or projects, you will need to manually type them in the task field.

Natural Language Parsing

When entering or editing a task, you can use natural language to set due dates. Type due: followed by a keyword, and it will fill in the correctly formatted date:

  • due:today -> due:2026-09-08
  • due:tomorrow -> due:2026-09-09
  • due:monday (or any day of the week) -> Snaps to the next occurrence of that day.

Note: This is a quick-entry feature. The actual file always stores dates in the standard YYYY-MM-DD format for compatibility.

Editing a Task

Simply tap any task in the list to open the Details dialog. You can edit the raw text or use the quick-action icons for Priority, Due Date, Recurrence, Context, and Projects.

Toggling Task Completion

There are four ways to toggle task completion:

  • Doubletap: This is configurable in Settings.
  • Checkbox: This can be hidden in Settings.
  • Swipe Right: This is configurable in Settings. You can choose to postpone by one day, complete, or do nothing with a right swipe.
  • Select: Long press and then tap the checkmark in the bottom menu.

Quick Add Shortcut

Long-press the VoDo.txt app icon on your home screen. You can launch a minimalist "Quick Add" popup or place the shortcut directly onto your home screen for one-tap entry.

Searching

The magnifying glass in the top right allows you to search the current filter set. If you want to search all tasks, you need to clear the filter first.

Quick Action

Automatically provides shortcuts for Links, Emails, and Phone Numbers found in your tasks.
