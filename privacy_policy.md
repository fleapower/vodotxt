# Privacy Policy for VoDo.txt

**Effective Date:** November 12, 2026

**VoDo.txt** is a free and open-source application provided for use as is.

This page informs users of the policies regarding the collection, use, and disclosure of Personal Information for this application.

## 1. Information Collection and Use
**VoDo.txt does not collect, store, share, or transmit any personal information or user data to external servers or third parties.** 

## 2. Google Drive Access
The application integrates with Google Drive to allow users to open, edit, and save text files directly. 
- **Data Processing:** All files accessed through Google Drive are processed locally on the user's device solely to provide the core functionality of the application.
- **No Storage or Sharing:** The application does not read the contents of Google Drive files for any other purpose, nor does it copy, store, or share user files or personal data. 

### Google API Services User Data Policy Compliance
VoDo.txt's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the **Limited Use** requirements.

## 3. Security
Because VoDo.txt does not collect, transmit, or store personal data or Google Drive files on external servers, there is no risk of user data being intercepted from external databases. 

## 4. Changes to This Privacy Policy
This Privacy Policy may be updated from time to time. Users are advised to review this page periodically for any changes. Updates take effect immediately upon being posted to this page.

## 5. Contact
Questions or suggestions regarding this Privacy Policy can be directed to vodotxt@gmail.com.
